Política de privacidad de Jarvis

Última actualización: 16 de noviembre de 2026

1. Responsable

Jacob Gómez, persona física, autor y único usuario de Jarvis. Contacto: jacobsen0105@gmail.com.

2. Qué datos de Google usa y para qué

  • Gmail (solo lectura, gmail.readonly): leer los correos del propio usuario para resumirle los importantes. Jarvis no envía, borra ni modifica correos.
  • Google Calendar (calendar.events): consultar sus eventos y crear, mover o borrar los que él pida expresamente.

Base legal: el consentimiento del propio usuario al autorizar la app y el uso doméstico de sus propios datos.

3. Dónde se tratan

  • En un servidor privado del usuario alojado en la Unión Europea.
  • Para entender las peticiones, fragmentos del texto se envían a la API del modelo de lenguaje Claude (Anthropic), que no los usa para entrenar sus modelos.

Los datos no se venden, no se ceden a terceros, no se usan para publicidad ni para entrenar modelos de IA.

4. Uso limitado de los datos de Google

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado.

5. Conservación

Los correos y eventos se leen al momento para responder y no se copian a otra base de datos. El historial de conversación con el asistente, que puede incluir fragmentos de ellos, y el token de acceso se guardan solo en el servidor privado del usuario, con acceso restringido, hasta que él los borra o revoca el permiso.

6. Derechos

Puedes revocar el acceso en cualquier momento desde myaccount.google.com/permissions. También puedes ejercer los derechos de acceso, rectificación, supresión, oposición, limitación y portabilidad escribiendo al correo de contacto, y reclamar ante la Agencia Española de Protección de Datos (aepd.es).
